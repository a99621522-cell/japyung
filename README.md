# 간명 — 자평진전으로 사주 보기

『자평진전(子平真詮)』(심효첨, 청 건륭 연간)의 조문으로 사주를 봅니다.
맞히는 것이 아니라 **왜 그런지 답할 수 있게** 보는 방법입니다.

## 이 앱이 하는 것

| 층 | 무엇을 |
|---|---|
| 만세력 | 태양황경으로 절기를 계산해 사주 여덟 글자를 세웁니다 |
| 오행 서사 | 「나는 무엇이고 무엇이 오가는가」를 먼저 그림으로 |
| 격·상신 | 태어난 달에서 격을 잡고 떠받치는 글자를 찾습니다 |
| 성패 | 원문 조문 114개로 짜임이 온전한지 봅니다 |
| 운 | 격과 상신에 맞는 취운 조문으로 대운을 판정합니다 |

모든 판정에 **원문 근거**가 붙습니다.

## 하지 않는 것

- 몇 년에 무슨 일이 있을지, 얼마를 벌지, 어느 자리에 오를지
- 몸에 관한 판단 (의사의 일입니다)
- 다른 사람의 명식을 대신 판단하는 것

## 개인정보

- **서버가 없습니다.** 넣은 생년월일시는 기기의 localStorage에만 저장됩니다.
- 네트워크로 나가는 것은 구글 웹폰트뿐입니다. 오프라인에서도 돕니다.
- 계정, 로그인, 추적, 광고 없음.

## 파일

```
index.html          앱 본체
engine.bundle.js    간명 엔진 (36개 모듈, 자동 생성)
manifest.json       PWA 매니페스트
sw.js               서비스 워커 (오프라인)
icon-*.png          아이콘
```

`engine.bundle.js`는 상위 폴더에서 `node bundle.js`로 다시 만듭니다.

## 스토어에 올릴 때

### 안드로이드 (권장: Bubblewrap)

```bash
npm i -g @bubblewrap/cli
bubblewrap init --manifest https://<도메인>/manifest.json
bubblewrap build
```

- HTTPS로 호스팅되어야 합니다 (GitHub Pages, Netlify, Vercel 등 무료로 가능)
- `assetlinks.json`을 `/.well-known/`에 두어 주소창을 없앱니다
- 스토어 등록 시 **개인정보 처리방침 URL**이 필요합니다 (아래 문안 참고)

### 정책 유의

구글 플레이는 점술 앱을 금지하지 않으나, 다음을 지켜야 합니다.

- **오해를 부르는 주장 금지** — 「100% 적중」 같은 문구를 쓰지 않습니다
- **건강·의료 조언 금지** — 이 앱은 몸에 관해 판단하지 않습니다
- **연령 등급** — 만 12세 이상 권장
- **결제 없음** — 인앱결제가 없으므로 결제 정책은 해당 없음

## 개인정보 처리방침 (그대로 쓰셔도 됩니다)

> **간명 개인정보 처리방침**
>
> 이 앱은 이용자의 개인정보를 수집하지 않습니다.
>
> 1. **수집하는 정보** — 없습니다. 이름과 생년월일시를 입력받지만, 그 값은
>    이용자의 기기에만 저장되며 개발자를 포함한 누구에게도 전송되지 않습니다.
> 2. **저장 위치** — 브라우저의 localStorage. 앱을 지우면 함께 사라집니다.
>    앱 안의 「저장 목록」에서 개별 삭제도 가능합니다.
> 3. **제3자 제공** — 없습니다.
> 4. **네트워크 통신** — 글꼴을 받기 위해 Google Fonts에 접속합니다.
>    그 외의 통신은 없으며, 한 번 실행한 뒤에는 오프라인으로 동작합니다.
> 5. **광고·분석 도구** — 사용하지 않습니다.
> 6. **아동** — 만 14세 미만을 대상으로 하지 않습니다.
>
> 문의: (연락처를 적으세요)
