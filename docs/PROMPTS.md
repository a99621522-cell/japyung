## 11. 현대 직업 적성 — 「지금 준비하는 일이 나에게 맞나」 (2026-10-10, 운영자 「예전에는 벼슬·농부·장사 정도였지만 지금은 연구원·대기업·공무원(경찰·행정…)·벤처 창업·연예인·유튜브·공기업으로 다양하다 — 사람들이 제일 궁금한 건 지금 취업 준비하는 게 자기에게 맞는지」)
**전제(바꾸지 말 것)**: 직업의 「내용」을 오행 물상으로 배속하지 않는다(「전자는 火, 생명은 木」 금지 — haeseol 선택 화법 규칙과 같음). 원전이 말하는 것은 **일하는 결**(십성의 작용)뿐이다. 그래서 직업을 「그 일이 날마다 요구하는 결」로 풀어 이 명식의 결과 맞대는 방식으로만 판정한다. 사람에게 등급을 매기지 않고, 직업에 순위를 매기지 않는다(「맞는 쪽·덜 맞는 쪽」만). 판정은 코드, 문장은 Gemini.
1. **직업 결 표** `jikeop.js` `직업표` — 통변 관례 표임을 머리에 명시(sageon 일표와 같은 지위). 직업마다 `{이름, 묶음, 요구결:[십성 작용 2~3개], 버팀결, 설명, 낱말:/정규식/}`. 최소 목록과 요구결 초안(사람 검토 전제, 표에 근거 줄 「통변 관례」):
   - 공무원 행정·일반직 — 정관(규범·절차) + 정인(문서·자격) / 공기업 — 정관 + 정재(안정 급여) / 교사·교원 임용 — 정인 + 식신(가르쳐 내놓음)
   - 경찰·소방·군·교정 — 편관(칠살: 압박을 견디고 다스림) + 겁재·양인(맞서는 힘) + 정관(조직) / 법조·감사·세무 — 정관 + 편관 + 정인
   - 대기업 사무·관리 — 정관 + 정재 / 대기업 영업·기획 — 편재(판을 굴림) + 식신
   - 연구원·R&D·대학원 — 편인(남들이 안 보는 것을 깊이 팜) + 식신(결과물로 내놓음) / 개발자·엔지니어 — 식신 + 정인
   - 의료·약사·간호 — 정인(자격) + 식신(돌봄을 내놓음) + 정관
   - 벤처 창업·스타트업 — 식상생재(상관·식신 → 편재) + 비겁(사람을 모음) / 자영업·장사 — 편재 + 겁재 / 금융·투자 — 편재 + 정재 + 편인
   - 연예인·방송 — 상관(드러냄) + 편재(대중) / 유튜버·크리에이터 — 상관 + 식신(꾸준히 내놓음) + 편재 / 작가·디자이너 — 식신 + 편인
   목록 밖 직업은 `낱말` 이 안 걸리면 「가까운 묶음」을 물음에서 고르지 말고 묶음 목록을 되물을 것.
2. **맞댐(세 책 따로, 섞지 않음)** `jikeop.맞댐(r, 직업)` →
   - 그릇(자평진전): 격·용법·상신이 가리키는 일하는 결(식신격 用편관 → 「만들어 내놓아 압박을 다스리는 결」)과 요구결이 겹치는가 — 상신 십성이 요구결에 있으면 「중심이 닿음」, 격 십성만 겹치면 「바탕이 닿음」, 요구결이 이 격의 꺼림(패격 원인 글자)이면 「부딪힘」
   - 흐름(적천수): 요구결 십성의 오행을 `jeokcheonsu.희기` 로 — 반기는 기운이면 「그 일을 할수록 풀리는 쪽」, 꺼리는 기운이면 「그 일을 하면 소모가 큰 쪽」
   - 밭(궁통보감): 직업과 직접 잇지 않는다(조후는 계절의 필요 — 일의 종류를 가르지 못함). 「밭은 이 물음에 말하지 않는다」고 한 줄만
   - 원국에 요구결 글자가 있는가(천간 투출·지지 통근, tonggeun) — 없으면 「타고난 결에는 없고 운에서 올 때 닿는 쪽」
   결과 `{직업, 자평:{닿음, 근거}, 적천수:{쪽, 근거}, 원국:{있음, 자리}, 한줄}` — 점수 합산 없음. 두 책이 갈리면 갈린다고만.
3. **물음 받기** — `mureum.갈래of` 에 「직업·적성」 갈래(맞을까·적성·어울리·준비하는 게·진로·전공·공시·임용·취준·이직할까 + 직업 낱말). 물음 속 직업이 하나면 그 직업만, 둘 이상이면 나란히, 없으면(「나한테 맞는 직업은?」) 직업표 전체를 맞대어 「닿는 쪽 셋·덜 닿는 쪽 둘」만(순위 말 금지, 묶음 이름으로).
4. **브리프** `[직업 결 맞댐 — 엔진 셈, 통변 관례 표]` 한 줄 + 지시: 한 줄 답 첫 문장은 「○○(지금 준비하는 일)는 이 명식의 ○○ 결에 닿습니다/덜 닿습니다」로 단정(결은 단정, 합격은 못박지 않음); 「쉽게 풀어 보면」에 그 일이 날마다 요구하는 결과 이 사람 결을 생활 장면으로; 덜 닿으면 같은 직업 안에서 결에 맞는 트랙(경찰이면 수사·행정·과학수사, 대기업이면 영업·연구·관리)을 엔진이 표에 둔 `트랙` 칸에서; 「내용(적성·성적·업계 사정)은 글자 밖」 한 문장; 직업에 오행 물상 배속 금지.
5. **화면** — 결과 화면 「일과 자리」 칩을 누르면 직업 칩 줄(공무원·경찰·대기업·연구원·창업·유튜버…), 고르면 맞댐 표(그릇·흐름 두 줄 + 원국에 있는가 + 시기 링크).
